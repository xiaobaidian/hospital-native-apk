# 医院盘库拍照 · 纯原生 Android App

纯 Kotlin + CameraX 实现的医院盘库/调拨现场拍照工具。相比混合版（Capacitor），后续更易做：
相机取景框实时水印、原生分享面板、扫码集成、更小体积/更跟手。

## 功能
- 系统默认后置镜头拍照（无网页黑屏/权限拦截，不强行切前置）
- 拍完自动烧录水印：`数量：X`（默认1）+ `时间：YYYY-MM-DD HH:mm`，左上角近不透明深色圆角底 + 纯白粗体，**专为 OCR 优化**（高对比、无描边、字号随图放大）
- 场景选择「盘库 / 调拨」
- 数量步进器（− / +）
- 缩略图横滑、可单张删除
- 一键「分享到微信」（装了微信直达微信，没装走系统选择器）
- **拍完自动存入手机「下载 / HospitalPhotoLog」文件夹**（文件管理器/微信可直接找到）；也可点「存到下载」手动导出，去重不重复
- 照片存本机磁盘（重启/切应用不丢）
- **音量键当快门**（现场戴手套/拿货时更顺手）

## 构建（无需本机装 SDK）
推到 GitHub 即自动跑 `.github/workflows/build.yml`（GitHub 构建机预装 SDK，
用官方源，约 3–6 分钟出 `app-debug.apk`）。

本地构建（需装 Android SDK）：
```
./gradlew assembleDebug
```

## 安装
下载 `app-debug.apk` → 传到手机 → 允许「未知来源」→ 安装 → 首次授权相机。

包名：`com.hospital.photolog`
